# PhotoDesk (Tribute)

Kodak DCS Photo Desk 4.3을 Windows 11(x64)과 macOS(Apple Silicon)에서 네이티브로 다시 구현한 프로그램입니다.
만든 사람: GO BANGWON (Korea). 버전은 `photodesk/__init__.py`의 `__version__` 한 곳에서 관리합니다.
원본과 같은 화면과 같은 동작을 목표로 합니다.

## 원본과 같은 인터페이스

화면 요소는 사용자가 가진 원본 설치 파일 `Photo_Desk_V_4_3_0.exe`에서 가져옵니다.
설치 파일과 그 안의 `PhotoDsk.exe`는 실행하지 않고 리소스 섹션만 읽습니다.

가져오는 요소는 다음과 같습니다.

- **메뉴와 단축키:** 메뉴(파일·편집·보기·이미지·정보·윈도우·도움말)와 명령 ID, 단축키(액셀러레이터 표), 오른쪽 클릭 메뉴.
- **툴바:** 아이콘과 버튼 순서.
- **패널:** 이미지 조절 패널, 이미지 정보 패널, 출력 히스토그램. 원본 대화상자 템플릿의 컨트롤 위치를 대화상자 단위(dialog unit)로 그대로 배치합니다.
- **대화상자:** 노출 보정, 노출과 톤(노출 히스토그램과 쉐도우·중간 톤·하이라이트 마커), 화이트포인트, 컬러 밸런스, 렌즈 최적화, 노이즈 제거(None/Basic/Advanced/Advanced with Moiré/Expert), 샤프닝(None/Low/Medium/High), 트리밍 비율, 보기 배율, 붙여넣기 옵션, 파일명 변경, 환경 설정, 인쇄 환경 설정, IPTC/작업 일지, 리뷰, 확인 대화상자(Yes/Yes to All/No), 진행 표시, 정보, 시작 화면.
- **그림과 문자열:** 비트맵(썸네일 정보 아이콘, 도구 아이콘, Kodak 로고), 커서(클릭 밸런스 스포이트, 손, 확대경, 트리밍 크기 조절), 상태 표시줄 형식, 오류 메시지.
- **번역:** 원본 번역표 `PhotoDeskUIStrings.u16`에 있는 10개 언어 공식 번역(한국어 포함). 원본 도움말(CHM)과 도움말 항목·상황별 도움말 버튼은 쓰지 않습니다.

## 원본과 같은 동작

- **화면 구성:** 폴더를 컨택트 시트로 열고 이미지 창을 따로 엽니다(MDI).
  - 이미지 조절 패널은 독립 이미지 창에서는 해당 창 오른쪽에, 내부 이미지 창(MDI)에서는 메인 창 오른쪽에 붙습니다. 컨택트 시트만 활성화하면 메인 창의 보정 패널은 숨겨집니다. 각 패널은 해당 이미지에만 적용되며, 보기 메뉴에서 활성 이미지의 패널을 숨기거나 다시 표시할 수 있습니다.
  - 화면 높이가 부족하면 우측 이미지 조절·이미지 정보·히스토그램 탭에 스크롤바가 자동으로 나타납니다. 히스토그램을 탭에서 분리하면 최소 크기로 돌아가며, 이후 크기를 자유롭게 조절할 수 있습니다.
  - 창 메뉴에서 활성 컨택트 시트나 이미지 창을 **별도 창으로 분리**해 앱 밖으로 옮길 수 있고, **앱 창에 다시 넣기**로 MDI에 복귀시킵니다. 보조 모니터에서도 사용할 수 있습니다.
  - 컨택트 시트는 50/100/200%, 이미지 창은 25/50/100/200%, 화면 맞춤, 기타(10–400%) 배율을 씁니다.
  - 이미지 창은 트랙패드 핀치와 Ctrl+휠 확대·축소를 지원합니다. 커서 위치를 기준으로 확대하며, 일반 휠은 스크롤로 동작합니다.
  - 이름순·날짜순으로 정렬합니다.
  - 썸네일 정보 아이콘은 밸런스, 라이팅, Look, 노이즈, 샤프닝, 노출, 태그, 읽기 전용, 음성, 파일 형식을 표시합니다. 완성 파일은 파일 형식, 태그, 읽기 전용만 표시합니다.
  - 아이콘에 마우스를 올리면 원본 문구로 설정값을 보여 줍니다. 예: "Sharpening: Amount = …".
  - 여러 장을 선택하면 포커스 이미지는 노란색, 나머지는 빨간색 테두리로 표시합니다.
  - 파일 메뉴에 최근 폴더 4개가 나옵니다.
  - 다른 프로그램(Camera Manager 등)이 폴더에 파일을 넣으면 컨택트 시트에 자동으로 나타납니다.
- **도구:** 선택, 트리밍, 클릭 밸런스, 클로즈업, 손 도구(컨택트 시트 스크롤 포함).
  - 클릭 밸런스는 클릭한 이미지와 같은 카메라(시리얼 번호)로 찍은 선택 이미지에 적용됩니다.
  - 트리밍은 비율 제한, 이동, 모서리·변 크기 조절을 지원합니다.
  - 클로즈업 창에서는 고정(Pin), 원본 보기, 25–400% 배율을 쓸 수 있습니다.
- **현상 설정:**
  - 밸런스: 사전 설정·클릭·사용자·자동.
  - 라이팅: 주광·텅스텐·형광등·플래시.
  - 화이트포인트 2000–7500K. 모든 밸런스 방식에서 쓸 수 있고(원본은 사전 설정·자동만), 슬라이더는 현재 밸런스의 색온도에서 출발합니다. 기종 제한 해제를 끄면 Pro 14n·SLR 이미지에서만 쓸 수 있습니다.
  - 사용자·자동 밸런스는 최초 Pro Back에서는 쓸 수 없습니다.
  - 컬러 밸런스 ±100.
  - 노출 보정 ±2EV(Pro Back은 ±1EV), 자동 노출 조정.
  - 톤(쉐도우/중간 톤/하이라이트 EV). 별도 저장값이 없으면 기본값은 -9.5/0.0/3.5이며, RAW와 사이드카에 저장된 톤은 유지합니다.
  - Look: 시스템 프로파일 폴더의 Custom Look도 포함합니다. DCS 3xx/5xx/6xx는 4가지, 620x는 6가지로 제한됩니다.
  - 렌즈 최적화(14nx, SLR/n, SLR/c). 자동 버튼은 사진의 무채색 영역에서 가장자리 색 번짐을 재서 강도를 정합니다(원본은 카메라 값을 되돌리기만 함). 잴 곳이 없는 사진은 카메라 값을 씁니다.
  - 노이즈 제거: 카메라별 종류(Basic/Advanced/Moiré/Expert)를 따릅니다. 원본에 없는 자동 버튼은 원본 해상도 사진의 49곳(7×7)에서 조각을 떼어, 밝기 구간별 고른 영역의 노이즈를 재서, 선택한 종류마다 노이즈를 목표 수준까지 줄이는 가장 약한 범위·강도(또는 Threshold)를 정합니다.
  - 샤프닝. 원본에 없는 자동 버튼은 같은 49곳의 조각마다 잰 윤곽 흐림의 중앙값으로 범위를, 노이즈 수준으로 Threshold를 정하고, 윤곽이 충분히 또렷해지는 가장 작은 양(최대 고)을 고릅니다.
  - 촬영 시 설정 사용, 자동 씬 밸런스.
- **설정 적용:** 설정은 선택한 모든 이미지에 적용되고, 주석은 포커스 이미지에만 적용됩니다. 완성 파일(TIFF/JPEG)에는 회전, 트리밍, IPTC, 태그만 적용됩니다. 대화상자의 미리보기와 "촬영시" 버튼도 원본처럼 동작합니다.
- **편집:**
  - 이름이 붙은 실행 취소/다시 실행. 예: "라이팅 취소".
  - 이미지 복사(트리밍 영역만), 설정 복사/붙여넣기, 붙여넣기 옵션. 클릭 밸런스는 같은 카메라 이미지에만 붙여넣습니다.
  - 태그, 태그 이미지 선택, 선택 반전.
- **파일 관리:**
  - IPTC/작업 일지: 불러오기(.ipt), 다른 이름 저장, 모두 적용, 마지막 정보 보기, 이전/다음.
  - 주석, 음성 재생.
  - 파일명 변경: `*` 위치에 일련번호를 넣으며, 원본 검사 규칙과 메시지를 따릅니다.
    - 한 파일은 확장자까지 입력하며, 확장자를 바꾸면 경고합니다.
    - 이미 있는 이름은 건너뛰고 계속할지 묻습니다.
  - 끌어서 복사/이동: 같은 드라이브에서는 이동, 다른 드라이브에서는 복사합니다. Ctrl은 복사, Shift는 이동, 오른쪽 버튼은 메뉴를 띄웁니다. 음성 파일도 함께 옮기고, 읽기 전용 폴더에는 놓을 수 없습니다.
  - 휴지통으로 삭제.
- **저장:**
  - 저장 형식: Standard TIFF, Standard JPEG, As Is.
  - RGB 작업 색 공간: Kodak DCS RGB, Kodak ERIMM, Kodak ProPhoto RGB, KODAK sRGB Display, sRGB IEC61966-2.1, Adobe RGB (1998), image-P3와 지원되는 시스템 RGB 프로파일. Agfa SWOP(CMYK)와 Lab to PCS는 제외합니다.
  - 위 7개 작업 공간 ICC는 앱 내부 리소스(`photodesk/data/working-spaces`)로 포함됩니다. 별도 색 공간 설치·다운로드·사용자 폴더 생성 없이 사용하며, 내보낼 때도 내장 ICC를 첨부합니다.
  - Adobe RGB (1998)와 image-P3는 [Adobe RGB 정의](https://www.adobe.com/digitalimag/pdfs/AdobeRGB1998.pdf) 및 [ICC Display P3 정의](https://registry.color.org/rgb-registry/displayp3)의 색도·전달함수로 생성한 독립 ICC 프로파일입니다(Adobe 배포 파일의 복제본 아님). image-P3는 P3 원색·D65·sRGB 전달함수를 사용하며, DCI-P3의 감마 2.6과 구분합니다.
  - 내보내기 크기: 퍼센트, 화면 채우기, 맞추기.
  - 해상도, 선형 모드, 8/16비트(8비트 완성 파일은 8비트 유지), 프로파일 첨부, JPEG 품질(고/중간/저), IPTC·EXIF 기록.
  - GPS 정보: TIFF 왼쪽 위에 표시(GPS 정보 렌더링), JPEG EXIF에 기록.
  - 이미지 편집기로 보내기, 저장 후 열기.
- **인쇄:** 인쇄, 미리보기, 페이지 설정. 컨택트 시트 인쇄 크기를 고를 수 있습니다.
- **기타:** 빠름/고품질 표시, 화이트 밸런스 파일(.wb) 저장, 상태 표시줄(이미지 수·선택 수, 픽셀 RGB, 좌표, 크기, 배율). 도움말 메뉴에는 포토 데스크 정보 항목만 있습니다.

색 처리는 원본의 Kodak ICC 프로파일을 그대로 사용합니다.
카메라 RGB에 Source Correction(카메라·광원)을 적용하고 ERIMM, Look 순서로 거쳐 RGB 작업 색 공간으로 변환합니다.

## 최초 설정

배포용 빌드(GitHub 릴리즈의 zip)에는 Kodak 프로파일 57개, 번역표(`PhotoDeskUIStrings.u16`), 원본 화면 리소스 묶음(`PhotoDeskUI.pack`)이 들어 있어 바로 실행됩니다.
화면 리소스 묶음은 원본 `PhotoDsk.exe`에서 대화상자 배치·메뉴·툴바·비트맵·커서·문자열만 뽑은 데이터이며, 원본 프로그램 코드는 들어 있지 않습니다.

소스에서 실행하려면 원본 설치 파일을 지정합니다. 처음 실행할 때 GUI가 묻고, CLI에서는 다음 명령을 씁니다.

```
photodesk install-profiles Photo_Desk_V_4_3_0.exe
```

이 명령은 Kodak 프로파일 57개, `ui/PhotoDsk.exe`, `ui/PhotoDeskUIStrings.u16`을 아래 위치에 풉니다.
위치는 환경변수 `PHOTODESK_PROFILES`로 바꿀 수 있습니다.

- Windows: `%APPDATA%\PhotoDesk\profiles`
- macOS: `~/Library/Application Support/PhotoDesk/profiles`

UI 언어는 시스템 언어를 따르며, `PHOTODESK_LANG=Korean`처럼 강제로 지정할 수 있습니다.

## 사용

```
photodesk [폴더|파일]                # GUI
photodesk convert <파일|폴더...> -o <출력폴더> [-f jpeg|tiff] [-s <작업 색 공간 프로파일>]
          [--bits 8|16] [--linear] [--look DCSPortraitLook.icm] [--lighting Tungsten] [--long-edge 3000]
          [-j <동시 변환 수, 기본 4>]
photodesk looks
```

`PHOTODESK_TIMING=1`을 지정하면 `convert`가 파일마다 디코딩·렌더링 시간을 표시합니다.

## 개발 / 빌드

```
pip install -e .[dev]
python -m pytest
python tests/gui_smoke.py <DCR가 있는 폴더> shot.png       # GUI 자동 점검
python tests/gui_commands.py <DCR가 있는 폴더> <스크린샷 폴더> # 모든 메뉴 명령과 대화상자 실행
python tests/bench.py <DCR 파일> [프로파일 폴더]                # 처리 단계별 시간 측정
pyinstaller --noconfirm packaging/photodesk.spec
```

빌드할 때 위 위치에 설치된 프로파일을 찾으면 프로파일·번역표·화면 리소스 묶음을 앱에 넣습니다(원본 exe와 도움말은 넣지 않음). 없으면 프로파일 없이 빌드되고, 앱이 처음 실행될 때 설치 파일을 묻습니다.
빌드 결과는 Windows가 `dist/PhotoDesk-Windows/PhotoDesk.exe`, macOS가 `dist/PhotoDesk.app`입니다. 폴더가 플랫폼별로 나뉘어 있어, 저장소를 Windows와 Mac이 함께 쓰더라도(시놀로지 등) 한쪽 빌드가 다른 쪽 결과를 지우지 않습니다.

### 성능

16.6MP DCR 기준(Windows, i9-12900H, 20스레드)입니다.

| 작업 | 최적화 전 | 최적화 후 |
|---|---|---|
| 전체 해상도 렌더링 | 10.6초 | 1.3초 |
| 이미지 창 미리보기(빠르게, 1600px) | 1.46초 | 0.21초 |
| JPEG 내보내기 1장 | 12.7초 | 3.1초 |
| 컨택트 시트 썸네일 40장 | 15.9초 | 4.9초 |
| 선택 이미지 40장 설정 변경 시 UI 멈춤 | 썸네일마다 렌더링 | 0.03초 |
| 슬라이더 30단계 드래그(이미지 창) | 렌더링 18회, 5.9초 | 렌더링 3회, 1.6초 |

- 색 변환 LUT 보간을 블록으로 나눠 모든 코어에서 병렬 처리합니다(출력 차이 1e-7 미만).
- 노이즈 제거를 OpenCV 연산으로 바꿨습니다(출력 동일).
- 썸네일과 이미지 창 렌더링은 백그라운드에서 하고, 새 요청이 오면 이전 요청을 건너뜁니다.
- 완성 파일(JPEG/TIFF)은 썸네일용으로 축소 디코딩하고, 전체 디코딩 결과를 캐시합니다.

이 최적화는 모두 운영체제와 무관한 코드라 macOS arm64 빌드에도 그대로 들어갑니다. 다만 Mac에서 직접 측정하지는 않았습니다.

`vendor/original/Photo_Desk_V_4_3_0.exe`와 `raw/*.DCR` 파일이 있을 때만 전체 테스트가 실행됩니다.
`.github/workflows/build.yml`이 Windows x64와 macOS arm64(`macos-14` 러너)를 빌드합니다.
Mac에서 직접 빌드하는 방법은 [docs/BUILD_MACOS.md](docs/BUILD_MACOS.md)를 보세요.

## 원본과 다른 점

- Camera Manager는 별도 Kodak 프로그램이어서 포함하지 않습니다. 메뉴에서 설치된 실행 파일을 지정하면 실행합니다.
- 렌즈 최적화, 노이즈 제거, 자동 밸런스 같은 Kodak 고유 알고리즘은 공개되지 않았습니다. 그래서 같은 조절 범위와 효과를 내는 방식으로 다시 구현했습니다.
